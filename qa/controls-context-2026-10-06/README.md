# Исправления автосбора, времени и контекста — 2026-10-06

Рабочее дерево уже содержало значительные незавершённые изменения. Этот проход меняет только соответствующие участки App.js, добавляет регрессионные тесты и три дополнительных функциональных контракта, включает тесты в test:ui-session. Существующие контракты не ослаблены, зависимости и native production-код не менялись.

Использованы Impeccable (harden / craft floor) и Emil Design Engineering, глобальная и проектная UX_RULES.md. Performance checklist применён к обработке жестов без расширения задачи до полного аудита.

| Before | After | Why |
| --- | --- | --- |
| Сохранённая новая сумма подменяла базовую цену; максимум снова удваивался | Отдельная базовая цена, фиксированный диапазон на время проверки; ручной ввод может расширить диапазон | Жест имеет предсказуемую шкалу, перезапуск проверки не удваивает отредактированную сумму |
| Каждый образец перетаскивания обновлял верхнее состояние и ledger | Предпросмотр суммы внутри модального компонента; итог передаётся владельцу после отпускания / accessibility adjustment | Не запускать обновления общего состояния и сохранение ledger на каждом движении; итог не теряется |
| Строки времени рассчитывались как 30 px, а accessible-кнопки занимали 44–48 px | Реальные строки и native snap равны 48 px | Центр колеса соответствует выбранному значению, цели касания доступны |
| Таймер фиксировал время через 220 ms, даже во время инерции; собственное обновление повторно центрировало колесо | Native momentum владеет завершением; fallback отменяется новым жестом, собственное выбранное значение не запускает выравнивание | Устранить скачки и прерывание выбора; часы и минуты объединяются через актуальный ref |
| Полупрозрачная кнопка времени разрешалась как тёмное native glass в светлой теме | Непрозрачная colors.card; числа календаря используют text, выбранные дни primary/onPrimary | Читаемые состояния во всех палитрах |
| CTA считал только уже наступившие проверки и писал «почти готово» при нуле решений | Учитывает незавершённые due + later-today, убирает дубликаты и завершённые карточки; завершение подчёркивается после реального прогресса | Честный остаток на текущий день; вчерашнее series resolution не скрывает сегодняшнюю карточку |

## Состояния и действия

| Состояние | Основное действие | Сохранённые дополнительные действия |
| --- | --- | --- |
| Автосбор, есть pending-карточки | Подтвердить проверенные результаты | Сумма жестом и вручную, сохранено/потрачено, «не знаю», позже, закрытие |
| Настройка времени / дней | Сохранить настройки карточки в существующем редакторе | Колёса, выбор дней, раскрытие времени, отмена/возврат |
| Главная, проверки на сегодня | Открыть решение | Выбор всех карточек, инструменты, история, сбережения, уход за персонажем |
| Нет pending / загрузка / невалидный ввод | Существующие условия родителя и валидация | Изменения не добавляют новых действий или конкурирующих CTA |

Проверены Fitts, Hick, Zeigarnik, Jakob, goal-gradient, Von Restorff и Miller в изменённом scope. Первичные действия различимы, вторичные остаются доступными; выбранные состояния календаря читаемы, остаток не выдумывается. У колеса сохранены тап и прокрутка, у слайдера accessibility increment/decrement. Контрактная проверка не считается ручной проверкой всех маршрутов.

- Functional parity: PASS, 231 контракт, 2024 фрагмента, 41 reachability pattern.
- Localization: PASS, все 12 словарей и native permission / App Shortcut resources. Новых или изменённых пользовательских строк нет; использованы существующие локализованные ключи. Проверены git diff --name-only, git diff -U0 и отдельный diff этого прохода.
- Themes: PASS, light/dark/PRO и шесть акцентов.
- UI session: 87 PASS; engagement: 157 PASS. Шесть новых regression cases исполняют реальные исходные callback-выражения и обработчики wheel: стабильный диапазон после 50 обновлений, ручное расширение, восемь карточек/полночь, геометрия, momentum/cancel, единственное сохранение последнего образца.
- Typecheck: PASS. Lint: 0 errors, 684 существующих/рабочего дерева warnings. git diff --check: PASS.
- check:release: PASS (runtime parity и size gates); это статическая проверка с существующим debug APK, не новая release-сборка.
- Analytics / native analytics contracts: PASS; attribution tests также проходят до security gate в verify.
- Последний npm run verify останавливается на check:security-audit: одна critical vulnerability в существующих backend dependencies. Gate не отключён; зависимости в этом исправлении не изменены. Остальные проверки после security gate не считаются автоматически выполненными этим запуском.
- Расчёт контраста по фактическим токенам: text/card 12.40–15.79:1, muted/card 4.96–8.10:1, onPrimary/primary 4.70–8.93:1. Это числовая проверка палитры отдельно от native screenshots.

## Native runtime и визуальные результаты

Пользователь явно разрешил запуск симуляторов. Создан отдельный iPhone 17 Pro / iOS 26.5: FE8E42E3-AA35-4965-957F-25D6B2BD604B. Android: отдельный от активных чужих задач AVD Almost_Decision_Followup_QA, emulator-5560, Android 16.

Использованы реальные компоненты из текущего App.js, автоматически извлечённые вместе с их лексическими зависимостями, в изолированном QA-контроллере. Это native React Native rendering, а не HTML-реконструкция. QA-контроллер использует синтетические карточки и передаёт суммы так же, как меняющийся snapshot; финансовые записи, покупки и entitlement не создавались. Это проверка компонентов, а не полный end-to-end запуск production-приложения, native release / device rollout или интеграции редактора с постоянным хранилищем.

- iOS: повторные диагональные drag вправо/влево не увеличили предел «До $30», значения изменились; close работает. Отдельно проверены тап часов и минут (10:00 → 11:00 → 11:01), быстрый часовой и медленный минутный swipe, сохранение выбранного значения при rerender.
- Android: реальные native row taps, быстрый/медленный swipe и rerender проверены с чтением accessibility hierarchy: 11:01 → 12:01 → 12:00. Диагональные drag сохранили предел $30.
- Обе платформы: 0 выполненных / 8 pending → 6 выполненных / 2 pending → сброс дня / 8 pending. Настоящая календарная граница дополнительно покрыта regression test; QA-кнопка меняет синтетическое состояние, часы системы не менялись.
- Календарь, недельные дни, автосбор и закрытие просмотрены в light/dark и всех шести PRO accent. Обнаруженная на первом проходе тёмная кнопка времени исправлена и повторно подтверждена в каждой палитре. Числа, подписи, выбранные состояния, thumb и equal-role controls читаемы и выровнены.
- Финальный отдельный проход колёс времени подтверждает все восемь палитр на каждой платформе после завершения анимаций: ios-wheel-confirmed-board.jpg и android-wheel-confirmed-board.jpg в artifacts/.
- Полные screenshots и журналы находятся в локальном artifacts/; генератор fixture и сценарии остаются воспроизводимыми. Ранние неудачные QA-запуски сохранены: неточный label закрытия, ранняя попытка при загрузке, tap сброса до завершения прокрутки. Последний context-confirm проходит после ожидания анимации; ошибки не представлены как PASS.
- Fixture использует замену mascot source на icon; Android APK не включает все fixture assets. Пропавшая декоративная картинка в hero не относится к изменённым контролам.
- Физические устройства, Dynamic Type/крупный шрифт, native RTL и визуальное выполнение всех языков, tablets, реальная доставка напоминаний, store purchase/restore и release attribution не проверены. Native QA не доказывает улучшение release frame time или latency; числовой speedup не заявляется.

Временные JS roots удалены после проверки; QA-копия iOS изолирована от production source. Android APK восстановлен из исходной QA-сборки без запуска, reverse-port удалён, собственные симуляторы и QA-сервер остановлены. Данные телефона не использовались. Попытка run-as backup старой Android QA-установки была недоступна, поэтому byte-for-byte сохранность её внутренних preferences не заявляется; тестовый контроллер не записывал product history и ledger.
