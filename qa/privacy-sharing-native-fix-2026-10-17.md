# Возврат из системного меню обращения — 17.10.2026

Пользователь подтвердил повторение после новой сборки и переустановки. Предыдущая замена Alert на Modal недостаточна; её нельзя считать устранением device-specific сбоя. Пользователь явно разрешил проверку на симуляторах. Другие изменения рабочего дерева сохранены.

Изменение: отдельный `AlmostPrivacySharing` для iOS выбирает окно текущей сцены, сохраняет UIActivityViewController до завершения UIKit dismissal, обрабатывает отмену/ошибку/повтор и отменяет незавершённые React touches при передаче и возврате. Native scroll recognizers и contentOffset не изменяются. На iPhone используется стандартная sheet-презентация, на iPad — anchored popover. Полный текст, тема и существующие идентификаторы обращения сохранены. Android и старые native shells сохраняют прежний Share transport. Для применения нужен rebuild iOS с новым native source. Выбор приложения не объявляется успешной отправкой/удалением.

Проверки исходников: RN Alert callback может предшествовать закрытию отдельного Alert-window; стандартный RN Share использует другую презентацию и completion раньше окончания dismissal. Это основания для устранения пересечения lifecycle и незавершённых touches, а не доказательство единственной причины зависания на физическом устройстве. Надёжного автоматизированного воспроизведения исходного зависания на симуляторе не получено.

Native build: xcodebuild Debug / iphonesimulator / x86_64 / CODE_SIGNING_ALLOWED=NO, отдельный task DerivedData — PASS, включая финальную компиляцию bridge. Свежая native сборка 8.0.1(133) установлена без uninstall на iPhone17/iOS26.5 и SE3/iOS17.0; наличие модуля подтверждено в реальном компоненте. Использован production-mode non-minified JS bundle в Debug native shell; Release performance/покупки этим не проверяются.
