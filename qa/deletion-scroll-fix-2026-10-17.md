# Исправление возврата из запроса удаления данных — 17.10.2026

Область: `src/privacy/CloudDeletionRow.js`, регрессионные тесты в `scripts/tests/cloud-deletion.test.cjs`, добавленный контракт `cloud-deletion-actions`. Предыдущие изменения рабочего дерева сохранены.

В прежнем пути `Alert.alert` запускал подготовку и mailto/Share из callback кнопки. В установленном React Native `RCTAlertManager` вызывает callback до `RCTAlertController.hide`; Alert использует отдельное key window. Скорость SDK getters определяла возможность пересечения системных презентаций. Это найденная по исходникам причина риска; воспроизведение зависания на устройстве в этой задаче не выполнялось.

Подтверждение заменено на контролируемый Modal в приложении: iOS запускает подготовку/передачу только из native `onDismiss`; Android — после commit скрытого Modal без зависимости от iOS-only события. Отложенное действие потребляется один раз, повторное нажатие блокируется. После отмены Share busy снимается, draft сохраняется для повтора; после ухода из Settings отложенная/незавершённая подготовка не открывает системное окно. Ошибка предлагает те же действия через собственный Modal без повторного Alert-window.

UX/Apple Design/семь правил проверены по исходникам для подтверждения, подготовки, ошибки, отмены и повторного запроса: основной шаг — подготовить; альтернативная отправка и отмена вторичны; действия не удалены; цели минимум 48 pt, перенос текста, ограниченная высота и прокрутка длинного содержимого, safe-area, мгновенная обратная связь на нажатие, активация на отпускании. Новых анимаций и материалов нет. Статус подготовки относится только к строке, не блокирует навигацию или ScrollView приложения. Новых пользовательских строк нет: повторно использованы существующие ключи всех 12 языков. Цвета из текущей темы, основной action использует primary/onPrimary.

Проверка взаимодействий на host: 14 тестов privacy-deletion PASS, включая шесть новых сценариев (iOS dismissal/двойное нажатие, недоступная почта/отмена Share/повтор, явная отправка/отмена/Back, ошибка/повтор, Android commit, unmount во время очереди/подготовки). Эти проверки не являются native визуальным или scroll-тестом.

Ограничения: запуск устройства/симулятора не разрешён в текущем разговоре. Фактические жесты и системные окна на iOS/Android, визуальные состояния light/dark/pro с акцентами, RTL и Dynamic Type на устройстве не проверены. Release-профилирование не выполнялось; изменения относятся к жизненному циклу окон, измеренного ускорения не заявляется. Атрибуция, настройки согласий и покупки не изменялись. Установка, отправка писем, удаление пользовательских данных и публикация не выполнялись.
