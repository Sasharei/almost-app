Original: https://kenney.nl/assets/particle-pack
Downloaded 2026-10-01 from the pack's public Godot distribution:
https://github.com/Calinou/kenney-particle-pack/tree/master/addons/kenney_particle_pack

Included unmodified: light_01.png, flare_01.png, star_04.png.
RewardBurst.js choreographs these raster textures using React Native's native
Animated driver. This is an app-specific animation, not a bundled Lottie movie.
No runtime network requests or additional native dependencies. Reduced motion
suppresses the burst; it never owns or delays reward granting.
