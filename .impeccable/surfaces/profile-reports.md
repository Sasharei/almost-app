# Profile reports surface

- Scope: the Profile navigation and its embedded weekly/monthly Reports section in `App.js`.
- Visitor mode: Operate.
- Audience and job: a person reviewing recent save/spend behavior who needs one clear conclusion and a useful next action.
- Primary task: switch report period, understand net outcome and trend, read the main insight, then set a category limit or create a goal.
- Content and proof: period archive, saved/spent totals, save share, cumulative balance trend, decision count, active days, strongest save/spend categories, ranked personal insights, and recommended next steps.
- Free state: reveal a personal signal count and preview copy, while keeping the full analysis and actions behind the existing Reports Premium gate.
- Constraints: preserve report generation, notification deep links, Premium access, analytics, category-limit routing, goal creation, accessibility, localization, and light/dark/PRO theme behavior.
- Chosen direction: “Главный вывод”, approved from `.impeccable/mocks/decision/profile-reports-focus-action.png`.
- Memorable moment: the cumulative result is drawn as the same luminous, gradient-filled chart language used by the app’s strongest analytics surfaces, then flows into one prominent contextual recommendation.
- Visual correction from device evidence: avoid tiny gray bullets and a placeholder sparkline; align the insight glyph to its heading, structure the main driver as title/value/context, never repeat the main insight inside the expanded report, and present supporting evidence as readable analytic modules.
- Unresolved: native device screenshots, large-font inspection, and tactile review require explicit permission to launch the app.
