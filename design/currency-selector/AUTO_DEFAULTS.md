# Автоматические язык и валюта — 2026-10-05

Первый запуск: читаем упорядоченные системные языки через установленный expo-localization/getLocales. Выбираем первый поддерживаемый язык; при недоступном API используем native preferences, затем Intl, затем en. Сохранённый язык имеет приоритет при следующих запусках.

Начальная валюта определяется по языку: en USD; ru RUB; es/fr/de/pt/it EUR; ar-sa SAR; ar-ae AED; zh CNY; zh-Hant TWD; ko KRW; ja JPY. Это соответствие поддерживаемому языку приложения, а не угадывание страны: английский сам по себе не различает США и Филиппины. Региональных правил и дополнительных UI-переключателей не добавлено. PHP доступен для ручного выбора.

В онбординге смена языка обновляет автоматически выбранную валюту. Ручной выбор сохраняет приоритет, в том числе после перезапуска. Старые сохранённые валюты считаем ручными, чтобы не менять существующие настройки. После завершения онбординга смена языка не меняет валюту. Полный сброс возвращает системный язык и его валюту. Маркер currencyManuallySelected сохраняется в существующем профиле, без отдельного storage key.
