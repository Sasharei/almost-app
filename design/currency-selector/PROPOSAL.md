# Селектор валют Almost — предложение на согласование

Статус: пользователь утвердил упрощённый вариант («Давай сделаем да»). Селектор внедрён; результаты проверок в IMPLEMENTATION.md.

## Рекомендуемый вариант

Упрощение после обратной связи: язык при первом запуске берётся из системных предпочтений телефона, валюта автоматически подбирается под язык, пока пользователь не выберет её вручную. Без дополнительных переключателей и рекомендаций.

Единый полноэкранный список с поиском. Онбординг открывает его из компактной строки с текущей валютой. В настройках он занимает существующий экран выбора валюты. На телефоне список использует всю доступную высоту; на планшете сохраняет ограниченную ширину и существующую модель навигации. Сохраняем стиль Almost: типографику приложения, существующие поверхности, цвета темы и акцент только у выбранной строки.

Причина: 34 валюты уже трудно просматривать горизонтально. Отдельный список позволяет искать и читать названия без сжатия и не отнимает место у языков и основного действия онбординга. Короткий dropdown не подходит для такой длины и клавиатуры; колесо требует знать место валюты в списке.

## Эскиз структуры

Онбординг, блок валюты под выбором языка:

```text
Валюта накоплений
┌─────────────────────────────────┐
│ ₽  RUB · Российский рубль      › │
└─────────────────────────────────┘

[         Продолжить             ]
```

Общий экран выбора:

```text
‹ Назад
Валюта накоплений
┌─────────────────────────────────┐
│ ⌕  Код или название валюты     │
└─────────────────────────────────┘
Выбрана
┌─────────────────────────────────┐
│ ₽  Российский рубль      RUB  ✓ │
└─────────────────────────────────┘
Все валюты
┌─────────────────────────────────┐
│ AED  Дирхам ОАЭ          AED    │
│ $    Аргентинское песо   ARS    │
│ $    Австралийский доллар AUD   │
│ …                               │
│ ₱    Филиппинское песо   PHP    │
└─────────────────────────────────┘
```

Это схема, а не проверенный рендер. В реальном макете символ, название, ISO-код и отметка имеют фиксированные отдельные колонки. Длинное название переносится, не перекрывая код. Список всех валют отсортирован по ISO-коду для предсказуемого порядка во всех языках; выбранная валюта закреплена сверху и не дублируется в списке. Флаги не нужны: валюты не всегда принадлежат одной стране.

## Поведение и состояния

- Обычный список: основное действие — нажать строку валюты; вторичные — поиск и Назад. Строка сразу применяет валюту, показывает выбранное состояние и возвращает на исходный экран. В онбординге дальше остаётся основное действие «Продолжить». В настройках сохраняется существующее немедленное применение.
- Поиск: код и локализованное название; регистр и диакритика не мешают поиску. `PHP` и «песо» находят филиппинское песо. Запрос «песо» может показать несколько подходящих валют. Во время поиска разделы уступают место единому списку результатов без дубликатов.
- Нет результатов: понятное сообщение и основное действие «Очистить поиск». Выбранная валюта не меняется.
- Назад/системный Back/закрытие без выбора сохраняют прежнюю валюту. Нажатие текущей валюты возвращает и подтверждает ручной выбор в онбординге; настройки сохраняют существующую обработку повторного выбора. Строки выбираются одним касанием и при открытой клавиатуре; клавиатура не закрывает результаты.
- Все варианты локальные: список и поиск работают офлайн и не ждут курсов. Загрузка/ошибка обновления курсов не блокирует выбор; сохраняются текущие правила кэша и резервных курсов.
- Первый запуск: первый поддерживаемый язык телефона → валюта этого языка. Ручная смена языка в онбординге меняет автоматически подобранную валюту. Ручной выбор валюты имеет приоритет и сохраняется после перезапуска. Сохранённые настройки существующих пользователей остаются прежними. Смена языка в настройках после онбординга не меняет финансовую валюту.

## Ограничения реализации после согласования

- Общий компонент/каталог для онбординга и настроек; сохранить все обработчики, persistence, события и существующие пути отмены/возврата.
- Полная кликабельная строка, минимум 48 dp на Android / 44 pt на iOS; базовая высота 64 с расширением для крупного шрифта. Отметка и доступное состояние selected, не только цвет.
- Поиск без автооткрытия клавиатуры; фокус при запросе пользователя. Очистка поля с доступным названием. Возврат screen-reader focus на исходное поле/экран.
- Новые названия, поиск, сообщения и accessibility copy локализовать во всех текущих языках, включая pt, it, ja, ko, zh-Hant и обе арабские локали. ISO-коды и символы — стабильные идентификаторы. RTL меняет направление layout, ISO-коды сохраняют LTR.
- Light, dark, PRO и все PRO-акценты используют роли существующей темы. Никаких отдельных ярких кнопок на каждой валюте. Открытие/закрытие — короткий переход до 250 ms с reduced-motion; результаты поиска без декоративной анимации.
- Список с виртуализацией, стабильными ключами и локальной фильтрацией; сетевые обращения для поиска не нужны. Проверить клавиатуру, короткие экраны, длинные названия и увеличенный шрифт.
- Перед изменением обновить/подтвердить функциональные контракты без ослабления текущих проверок; после изменения выполнить функциональные, localization, themes и общие проверки. Симулятор/устройство не запускать без явного разрешения в текущем разговоре.
