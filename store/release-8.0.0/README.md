# Almost Savings 8.0.0 — Android 128 / iOS 129

Подготовлен релиз с анонсом полного редизайна, улучшенной навигации, целей, бюджета, прогресса, виджетов и Almi. iOS-тексты дополнены Shopping Pause и автоматизацией Apple Pay; Android-тексты описывают поддерживаемый импорт уведомлений. Ограничения платформ и обязательное включение пользователем отражены в текстах.

## Файлы

- `release-notes.md`, `metadata.json`: тексты для 14 локализаций каждой платформы.
- `app-store/`, `google-play/`: отдельные тексты для магазинов.
- `app-store-review-notes.txt`, `google-play-review-notes.txt`: инструкции проверяющим.
- `builds/Almost-8.0.0-128-store.aab`: подписанный Android bundle, 86 454 131 байт; runtime и конфигурация совпадают с исходной Gradle-сборкой побайтово.
- `builds/Almost-8.0.0-128-native-debug-symbols.zip`: уже прикреплены к версии 128 для расшифровки native crash reports. ReTrace mapping сохранён внутри AAB.
- `builds/ios-export-129/Almost.ipa`: готовый подписанный IPA, 98 898 486 байта; Family Controls проверен в приложении и трёх расширениях.
- `builds/Almost-8.0.0-129.xcarchive`: успешный iOS Release archive с четырьмя расширениями.
- `SHOPPING_PAUSE_SETUP.md`: точные шаги получения Family Controls Distribution и подписи.
- `release-manifest.json`: фактическая готовность, неподтверждённые проверки и состояние магазинов.

## Состояние магазинов

App Store Connect: тексты What’s New сохранены и прочитаны обратно во всех 14 локализациях; инструкции проверяющему сохранены. Финальная сборка 129 загружена, обработана Apple до VALID и привязана к черновику 8.0.0 вместо сборки 128. 9 октября 2026 в 14:48 (Asia/Riyadh) версия 8.0.0 (129) отправлена на ревью: WAITING_FOR_REVIEW, заявка cf4154ff-af95-4850-aff5-f9d6191dfa46. Отдельная заявка Header/Search Results a9c27b64-e33c-4a3c-988a-3a1987101989 отменена; изображения связаны с 8.0.0 и включены в проверку версии. Публикация после одобрения остаётся ручной.

Google Play: черновик 8.0.0 сохранён; сервер сохраняет 12 языков release notes. Для `es-419` и `zh-CN` файлы подготовлены, но консоль удаляет эти теги после сохранения. В черновике основной карточки присутствуют 14 локализаций; дополнительные release notes необходимо повторно применить, когда консоль начнёт их сохранять. AAB 128 сохранён в черновике; ReTrace mapping и native debug symbols прикреплены. Google подтверждает поддержку 16 KB. Пользователь сообщил, что отправил Google Play на ревью; статус Google в текущем шаге независимо не перепроверялся.

## Проверки и оставшиеся ограничения

`npm run verify` прошёл: функциональный паритет, локализация, темы, Shopping Pause, attribution/native analytics, backend и остальные репозиторные проверки. AppLovin cost gate отдельно прошёл с существующей приватной конфигурацией. Финальный Android size gate прошёл. iOS native analytics проверены также по Info.plist готового архива.

Физическая проверка выявила плохой контраст кнопки Close на Screen Time shield в iOS 27.2. Исправлена только пара цветов в ShoppingBlockerShield.swift; действие сохранено. Новый iOS 129 прошёл полную `verify`, локализацию, темы и функциональный паритет. Блокировка Amazon, сохранение паузы после обновления и Close с исправленным контрастом проверены на Ad Hoc-экспорте того же архива. Симулятор не запускался. После явного разрешения пользователя Release-сборка установлена и запущена на физическом iPhone Рей (iPhone Air, iOS 27.2). Просмотрены Today, Profile, настройка Shopping Pause в светлой теме и системный shield в тёмном оформлении. Полная матрица light/dark/PRO и истечение 30-минутного доступа не проверены. Остановка теста через Profile ожидает помощи пользователя: удалённая прокрутка Device Hub не срабатывает, затем Mac оказался заблокирован. Пауза пока включена, цель EUR 1. На iPhone: Almost → Profile → Shopping Pause → Stop. В историю не добавлялись тестовые записи. См. `checks/physical-shopping-pause.md`.

Family Controls Distribution назначен; включён для приложения и трёх расширений, App Store профили созданы и проверены, IPA успешно экспортирован.

Релиз пока NO-GO: остаётся QA-003 (iOS audio SIGILL), нет физической release-проверки установки и purchase postbacks на обеих платформах. Требуется сверка App Privacy/Data safety и актуальных скриншотов с финальной версией. Текущая опубликованная App Privacy содержит старые категории, включая Other User Content для tracking; декларации в этой задаче не менялись.
