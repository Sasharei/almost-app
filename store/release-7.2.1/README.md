## Что изменено в позиционировании

Название адаптировано по смыслу «меньше покупать, больше сберегать» с учётом лимита 30 символов. Дополнительный акцент: симуляция ритуала покупки без оплаты. Пользователь добавляет желание и цену, отмечает решение не тратить и видит сумму, которую сохранил. Формулировки не обещают реального оформления заказа, банковского перевода или гарантированной экономии. Almost Premium обозначен как отдельная покупка внутри приложения.

EN title: **Almost: Shop Less, Save More** (28/30). Subtitle: **Stop Impulse Buying** (19/30). В keywords перенесены savings, tracker и no spend; длина поля — 98/100.

RU title: **Almost: трать меньше и копи**. Subtitle: **Копилка, цели и бюджет**.

В Apple promo объясняет выгоду, а поисковые слова распределены между названием, subtitle и keywords. В Google отдельного поля Apple-style promo/keywords нет; тезис использован в short description и связном описании.

## Основание релиз-нот

Исправления purchase verification и secure storage подтверждены коммитом b76dc04 и SECURITY_FIXES_2026-09-13.md. Исправления сумм, напоминаний и повседневных контролов присутствовали в рабочем дереве до этой задачи: App.js, temptationLifetimeStats, subscriptionWatch, LiquidGlassTabBar и соответствующие тесты. Они не переписывались в рамках подготовки версии. Существующий diff этих десяти файлов после работы совпал с исходным побайтно.

Обновлённый onboarding уже выпускался в 7.2.0 и не представлен новой функцией 7.2.1. Симуляция покупки — описание существующей механики, а не заявление о новой функции этого патча.

## Проверки

Пройдены:

- `npm run check:functional-parity`: 140 контрактов, 1455 фрагментов поведения, 36 проверок достижимости.
- `npm run check:localization`: покрытие всех 11 исходных языков приложения.
- `npm run check:themes`: light, dark, pro и 6 акцентов PRO.
- `npm run check:analytics-contract` и `npm run check:native-analytics-config`.
- `npm run verify`: полный набор gates, тесты, typecheck, lint, security, backend и runtime parity; exit code 0.
- Проверка всех лимитов полей и уникальности locale/keywords; все 13 использованных в консолях наборов по 8 полей первоначально сверены с локальным JSON по контрольным суммам. После окончательного выбора Shop Less, Save More все 25 названий (13 Apple + 12 Google) повторно проверены после перезагрузки. В локальном пакете обновлены все 14 языковых наборов, включая дополнительные локализации. Подзаголовки и остальные тексты сохраняют подготовленное объяснение механики и функций.
- `git diff --name-only` и `git diff -U0`: новые изменения касаются версии и релизных материалов; пользовательский UI-diff сохранён.

Lint завершился с существующими предупреждениями и без ошибок. size:check проверил уже имевшийся APK (79.2 MB), а не новую сборку 7.2.1; он сообщил рост относительно baseline, лимит не превышен. Этот результат не доказывает размер будущего релиза.

Визуальный просмотр приложения в light/dark/pro не проводился: эта задача не меняет UI, а запуск симулятора/эмулятора не был разрешён. Статическая theme-проверка выполнена. Данные проверки не заменяют реальный release QA существующих изменений интерфейса.

## Перед будущим выпуском

Текущая задача полностью ограничена подготовкой. Для последующего выпуска понадобятся сборки; EAS использует remote app-version state и autoIncrement, поэтому фактические build IDs нужно сверить при сборке. В Apple поля App Review contact phone/email остаются пустыми — значения не выдумывались.

Так как в будущую сборку входят ранее внесённые изменения покупок и защищённого хранения, до rollout остаются обязательными release-проверки fresh-install, покупки/подписки и атрибуции на реальных iOS и Android согласно AGENTS.md и ATTRIBUTION_RELEASE_GATE.md. Backend-изменения не развёртывались этой задачей. Эти шаги здесь не выполнялись и не считаются подтверждёнными.
